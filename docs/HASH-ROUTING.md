# Hash 路由改造计划

## 依据与范围

采用 Vue Router 官方的 `createWebHashHistory`：[Different History modes](https://router.vuejs.org/guide/essentials/history-mode.html)。页面地址的 `#` 片段由浏览器处理，服务器继续提供根页面、API 和文件资源。

## 目标行为

- 首页 `/#/`；登录 `/#/login`；阅读深链 `/#/reader/19?session_id=…`；Zotero 集成 `/#/integrations/zotero`。
- 保留现有工作台视图、打开标签、布局与草稿的持久化方式，本次不改变数据结构。
- 旧的 `/reader/:id`、`/login`、`/register`、`/accounts`、`/integrations/zotero` 及首页查询链接在前端启动前转为 Hash 地址，保留查询参数和阅读锚点。服务器保留旧页面兜底用于已有书签。
- 未登录访问深链，登录成功后回到原页面；会话过期也保留返回目标。主动退出和改密后回登录页，不保留身份数据。
- 返回地址仅接受站内页面路径，拒绝外部地址、协议相对地址和登录循环。
- 新生成的安全登录入口及 Zotero 配对链接直接使用 Hash 路由。API、PDF、下载地址保持原路径。

## 实现顺序（按此执行）

1. 增加统一的页面地址、旧链接迁移及安全返回目标工具；启动时先迁移旧链接。
2. 切换 Vue Router，调整认证守卫、登录、退出、改密、会话过期和首页链接。
3. 更新服务端生成的登录、配对地址及部署文档，保留旧入口兼容。
4. 执行前端回归与构建，后端认证/同步/路由专项；上线后检查匿名深链、刷新、登录返回和文件/API 地址。

## 验收与回退

验收：新地址含 `/#/`；旧书签不丢论文/会话参数；直接打开和刷新不出现 404；认证跳转无站外跳转、无循环；PDF 与同步接口不受影响。无数据库迁移、无模型调用。

回退：恢复上一版应用镜像与前端构建即可，保留工作区数据库。验收结果记录在变更记录中。
