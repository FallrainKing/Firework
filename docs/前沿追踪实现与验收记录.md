## Markdown 统一解析与显示

按用户补充，使用 [Marked](https://github.com/markedjs/marked) 18.2.1 作为统一 Markdown 底层，DOMPurify 3.4.18 清理 HTML。官方明确 Marked 不负责输出清理，因此使用统一解析后清理的路径，详见 [Marked 使用说明](https://marked.js.org/)。

`frontend/src/shared/markdown.ts` 提供解析 tokens、渲染 HTML 和兼容 HTMLElement 接口；讨论回答、会话历史、译文和前沿报告均调用它。旧 `frontend/public/md.js` 简化解析器被移除，依赖通过构建打包，不使用运行时 CDN。原文 Markdown 仍存储并用于导出，不把渲染后的 HTML 写回替换原文。

统一样式覆盖标题、引用、嵌套列表、表格、代码块、图片和禁用的任务复选框；脚本、事件处理、危险链接和交互表单不可执行。该解析器不自动提供公式排版或代码语法高亮，后续扩展不与已支持 Markdown 语法混称。
