## 本批验证与范围

前端 **252 项**测试及类型检查/生产构建通过；隔离后端 **95 项**相关回归通过，覆盖分类生命周期、论文/会话、论文回收站、Zotero 交换、用户资料、账号隔离、迁移、前沿和导读。本批未调用真实研究模型；不将这组相关回归称为后端全仓库测试。

首批交付与后续依赖见 [实施计划](IMPLEMENTATION-PLAN.md)。分类软删除只影响导航/有效归属，不删除论文/文件/项目/批注；已归档关联在编辑论文时也保留以供恢复。恢复同名冲突会明确拒绝，不静默合并或改名。

认证核对纠错：`profile_view()` 的 False 是无认证本机模式的默认值，已认证请求早已有 `account_profile()` 覆盖为 True。此前总览漏看路由层，误将其列为线上认证缺陷。本批修正记录、增加真实认证回归，并返回/展示 login_policy；没有扩大登录或注册范围。

自定义服务商兼容、视觉/1M、真实计费、完整深读质量与生产全量恢复演练仍未验证。Zotero 0.1.4 的历史合成资料交换验证不等于原生批注/阅读状态回流已实现。
