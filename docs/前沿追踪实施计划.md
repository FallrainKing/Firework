# 前沿追踪与论文库导航实施计划

日期：2026-11-19。状态：实施计划已整理，功能开发尚未开始。

设计依据：[前沿追踪与论文库导航设计方案](前沿追踪与论文库导航设计方案.md)。代码基线为已核实的 `ff7d880`；开始开发前再次核对服务器版本及工作区，保留其他智能体或用户的修改。

## 1. 本轮交付范围

完成论文库分类侧栏、前沿追踪模块、主题配置、现有 Agent 执行、论文及项目发现、与已有库统一去重、堆叠时间线报告、人工批准入库、按小时间隔持续运行。

优先复用 Nature 系列发现工作流，接入完整技能资源及必要依赖。现有 `paper_discover` 保留为可用回退。kelip 交互精读以独立适配任务接入，不能代替后台发现，也不作为定时追踪的默认步骤。PaperSeek 本轮借鉴任务与结果组织，其引擎接入在基础闭环之后单独验证。

不自动启用新建主题，不以演示数据或模型口头报告作为功能验收结果。

## 2. 执行顺序与依赖

```mermaid
flowchart LR
  A[基线及接口冻结] --> B[实体与全局去重]
  B --> C[Agent与技能发现]
  C --> D[报告时间线]
  B --> E[批准入库与库侧栏]
  D --> F[周期调度及恢复]
  E --> F
  F --> G[完整回归与发布]
```

代码按下列批次形成可检查的提交。每个批次都提供真实保存状态、错误和空状态，不提前显示未支持的操作已成功。

## 3. 分批任务

### 第 0 批：基线、技能清单与契约

- [ ] 核对远端分支、提交、未提交改动、数据库迁移编号和 Runner 协议；准备隔离开发副本。
- [ ] 盘点服务器实际注册的 Skills、完整资源、依赖、工具和模型能力。
- [ ] 为 Nature 发现能力建立兼容配置，列出已满足/缺失项；保留原始来源与许可。
- [ ] 固定主题配置、候选身份、报告版本、审批与导入的接口及状态定义。
- [ ] 明确首轮可用的一个学术来源和一个项目来源，禁止未接入来源出现在可执行选项中。

完成标准：输入输出契约可供后续代码共用；清楚说明技能可用范围，不产生模型费用。

### 第 1 批：数据库与已有资料去重

- [ ] 增量建立主题、配置版本、执行、实体、标识别名、快照、出现记录及正式库关联表。
- [ ] 从现有论文与已完成导入建立可重跑的身份映射，记录歧义项，不改动批注、会话和阅读进度。
- [ ] 统一 DOI、arXiv 基础 ID、仓库稳定 ID、规范 URL 和版本标识。
- [ ] 实现“全新、已在库、已有候选、已有更新、疑似重复”分类；可靠身份确定性匹配，模糊标题只提示。
- [ ] 以业务版本指纹判断实质变化，排除抓取时间和普通热度变化。
- [ ] 所有入库路径在资料提交时维护身份关联，并处理活跃导入请求，防止后续手动导入绕过去重。

完成标准：已有论文首次被发现即识别为已在库；不同论文不因标题相近被合并；跨主题共享身份并分别保留相关性决定。

重点测试：DOI 不同写法、arXiv v1/v2、同题不同文、预印本与正式版交叉标识、仓库改名/fork、回填重跑、资料创建并发。

### 第 2 批：现有 Agent 与技能执行闭环

- [ ] 新增主题增删改查与配置版本，保存后默认暂停；暂不开放自动物理删除历史。
- [ ] 为追踪增加受限运行上下文，扩展应用与 Runner 兼容协议及 `purpose`，不把完整配置塞进聊天输入。
- [ ] 接入 Nature 发现流程所需资源和实际工具；以版本锁定的适配配置声明背景执行模式。
- [ ] 补齐受限项目搜索、按范围搜索、分页与来源能力探测。
- [ ] 实现绑定本轮 Run 的候选暂存工具，返回平台去重标签，再由同一 Agent 生成简报。
- [ ] 校验结构化候选、真实证据 ID、覆盖与截断信息；业务失败与 Agent 回答完成分别记录。
- [ ] 保留现有会话、取消、用量与进度查询，不另写模型执行引擎。

完成标准：固定样本跑通后，一次最小真实执行能得到有来源的论文/项目候选，并正确识别其中已有资料。没有项目工具时不得宣称本批完整通过。

重点测试：来源失败、部分完成、没有结果、输出不合规、取消、重复提交、技能依赖缺失及工具权限越界。

### 第 3 批：前沿追踪页面与堆叠时间线

- [ ] 在“读论文”和“论文比较”之间增加“前沿追踪”，同步前后端工作区枚举及恢复逻辑。
- [ ] 新增主题侧栏、配置表单、运行记录、发现池与报告页；领域/关键词/团队/作者支持可选及已有/新增选择。
- [ ] 报告按日期分组、最新在上，卡片纵向堆叠，支持多条独立展开及加载更早记录。
- [ ] 同轮重生成归入原节点切换版本；新周期新增节点，保存不可变内容与引用。
- [ ] 卡片分列新增资料、已有更新、已知无变化、覆盖异常；重复无变化默认折叠。
- [ ] 已在库资料直接链接原条目；操作区实时读取入库/审批状态，历史正文保持不变。
- [ ] 保存主题筛选、展开和滚动位置；新报告提示到达，不强制跳顶；已读标记与批准分开。

完成标准：真实运行结果可在时间线上展开、溯源、恢复；空闲查看、刷新和切换标签不触发模型。

重点测试：同时间戳稳定分页、不重不漏、报告版本、迟发现旧论文的日期显示、窄屏布局、历史卡片动态状态。

### 第 4 批：批准入库与论文库左栏

- [ ] 新增正式项目实体、项目分类及论文—项目关联；项目不伪装为论文。
- [ ] 实现单条和有界批量批准、忽略、恢复，支持分类选择及内联新增。
- [ ] 批准事务再次检查已有资料和活跃导入；相同请求复用结果，冲突明确返回。
- [ ] 论文支持仅保存书目和补充全文，全文获取继续复用已授权导入流程；项目直接保存已验证资料。
- [ ] 把审批结果和入库执行状态分开保存；部分成功逐项展示，失败可重试。
- [ ] 管理页增加专用左侧导航：资料类型、领域分类、阅读状态、全文状态、追踪来源。
- [ ] 重构模块侧栏选择，避免与外层阅读导航重复；保留图文卡片、批量操作和任务会话入口。
- [ ] 由后端提供与筛选口径一致的分类计数，切换分类与搜索联动。

完成标准：批准前正式库不变；批准后不重复资料；有 PDF 可恢复阅读，无 PDF 有补充入口；项目可独立管理。

重点测试：两主题同时批准、发现后手动入库、导入进行中再次批准、重复点击、部分失败、分类变更及已有阅读功能回归。

### 第 5 批：定时执行、预算与恢复

- [ ] 扩展现有定时任务类型，追踪主题与调度列表使用同一条记录，不新增第二套独立 cron。
- [ ] 增加持久分派记录、时段唯一键、固定请求键及状态不明时的查询核对。
- [ ] 保存各来源成功检查水位及未完成游标，支持重叠窗口、有限退避和同主题防重叠。
- [ ] 暂停只停止后续触发；取消当前运行另行处理，必要时转发到外部 Provider。
- [ ] 保存配置、技能版本与预算快照；增加单轮及周期预算预留、结算与未知费用提示。
- [ ] 已忽略的无变化条目不重复提醒，实质更新单独展示，不覆盖原决定。

完成标准：连续两轮正确去重；运行重启或提交超时不盲目重新收费；来源失败和预算截断不会推进完整覆盖水位。

重点测试：重复时段、进程重启、队列满、预算不足、部分来源失败、配置变更、暂停与取消区别。

### 第 6 批：完整验收与发布

- [ ] 运行相关后端一致性测试、前端测试、类型检查和生产构建。
- [ ] 备份数据、保留回退镜像；数据库迁移与身份回填先演练，验证旧阅读状态可恢复。
- [ ] 同步应用与 Runner 的兼容版本；不兼容时禁止追踪执行并给出明确提示。
- [ ] 最小真实验证后不重复消耗模型做截图或刷新检查；调度用固定样本验证时序。
- [ ] 浏览器验收：库左栏 → 新建主题 → 发现 → 去重 → 时间线 → 批准 → 正式库 → 阅读/项目详情。
- [ ] 首个主题保持暂停，由明确启用动作开始周期运行。
- [ ] 更新架构、环境、接口、未完成清单及交付记录，提交 Git 并记录版本和验证结果。

完成标准：上述完整路径实际可用；失败路径可定位、可重试；原有阅读、比较和定时任务正常。

## 4. 后续增强，单独排期

- [ ] kelip 六站交互精读：材料、图像能力、站次恢复与证据产物完整适配。
- [ ] Nature 全文对照、Paper Card、自主批量精读按任务分别接入，不降格为通用短摘要。
- [ ] PaperSeek 可选后端：固定版本、能力探测、分页、幂等、取消及外部模型费用验证。
- [ ] 固定时刻/周周期报告、引用扩展、站外通知与更细粒度知识关联。

## 5. 进度记录约定

每批记录实际完成内容、测试结果、剩余问题及提交号。只有达到完成标准才勾选；基础界面可见、请求已提交或 Agent 已回复均不等于端到端完成。计划不以未经验证的工期承诺代替验收。
