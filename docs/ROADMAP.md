更新：2026-11-23。以 `63de695` 为当前基线；完整功能、架构、接口规划、批次和验收统一见 [实施计划](IMPLEMENTATION-PLAN.md)。本文仅为路线摘要，不另维护一份不同的待办。

## 范围调整

- 优先：原清单1–5、7、11、12、13，即原生智能体、本机/多Provider、外部MCP、模型与执行配置、会话调试、材料与产物、Zotero回流、知识记忆、外部接口与部署。
- 删除：原6“用量与成本扩展”专项，不建设请求账本、费用对账、累计账单硬限额或追加额度续跑。保留既有配置与运行保护。
- 用户本地Skill负责：原8深读材料链、9高级Skill工作流、10前沿研究增强。平台仅在Skill就绪后做前端展示与交互适配；通用权限、文件和产物接口由优先项统一提供。

## 按功能归类

| 类别 | 工作 |
| --- | --- |
| 智能体工作台 | 原生终端、权限答复、授权文件/代码操作、会话检查、回放与分支 |
| 接入与配置 | 本机Bridge、多Provider、外部MCP、多模型、角色及版本化方案 |
| 论文与研究资产 | 材料清单、文件版本状态、统一产物与引用、批注版本处理 |
| Zotero互操作 | 成果子笔记、选定分类监听、批注/阅读状态与冲突协议 |
| 知识管理 | Skill候选、审核发布、修订/撤销、带证据的授权召回 |
| 开放与运维 | 外部数据接口、审计、Runner容器化、恢复演练、后置多副本协调 |
| Skill前端适配 | 按用户提供的Skill和样例接入阅读、批注、报告及候选展示 |

## 按架构推进

执行隔离/Provider → 配置授权/MCP → 事件与检查器；材料与产物契约可并行推进，随后支撑Zotero和知识召回。展示层贯穿各批；身份授权和备份恢复贯穿全程。

后续批次：M1执行隔离与原生交互 → M2配置/MCP/接入 → M3会话检查与外部控制 → M4材料与产物 → M5 Zotero成果桥、M6知识记忆。详细依赖与可并行范围以主计划为准。

当前已交付的Skill后台、流式回答、原生历史查看、分类/论文回收站、手动Zotero交换和个人API连接不重新列为待重建能力。共享协作、公开注册、站外推送及完整Zotero云生态不在此次优先范围。
