# Firework 项目状态

更新：2026-11-20。业务迁移 0016、独立身份 schema 2、Runner 协议 5。远程默认分支为 `main`，文档只描述当前实现。

## 已实现

| 模块 | 当前能力 | 关键边界 |
| --- | --- | --- |
| Zotero 手动交换 | 插件打包、设备配对/撤销、书目/分类/标签/PDF、出站队列与重试 | 0.1.1 已由用户确认安装与配对；0.1.3 升级后真实双向验证待完成；原生批注和 Connector 自动同步未实现 |

| 阅读 | 多论文标签、可调三栏、批注/高亮/翻译、位置/草稿恢复 | 文件换版隔离，扫描材料无自动 OCR |
| 讨论 | 原生会话延续、模板、图片、选区、Enter 发送、进度/取消 | 图片理解取决于模型，费用是 CLI 估算 |
| 论文库/导入 | 分类、卡片、元数据编辑、PDF/arXiv/DOI/URL | 公开来源不保证获取全文 |
| Skills | ZIP 预检/安装、分类、版本、启停、资源、审计与最小验证 | 不执行任意上传脚本；安装不等于效果通过 |
| 前沿追踪 | 多维主题、arXiv/Crossref/GitHub、去重、时间线报告、审批入库 | 新主题默认暂停，元数据不等于全文审查 |
| 调度 | 会话/追踪间隔运行，启停、状态与错误 | 非任意 Cron，多副本与全局预算未实现 |
| 导读批注 | 明确确认触发 Skill，结构化总结/重点/解释，核验后高亮 | 最多 6 页文字材料，未接入图像/代码 |
| 认证与用户 | 登录、退出、改密、管理员账号管理、独立研究空间 | 公开注册关闭，当前仅原管理员可登录；没有共享库或跨账号协作 |
| 运维 | Compose、用户 Runner、增量迁移、备份/恢复脚本、零模型冒烟 | 生产全量恢复演练尚未完成 |

## 发布与验证

- Zotero P0/P1 功能提交 `b97000e` 已部署：集成页与公网 XPI 下载可访问，文件哈希与本地构建一致；真实 Zotero 的 0.1.1 安装与配对已由用户完成。
- 已部署 Firework 阅读工作台、独立账号与应用网页登录；公网不再启用浏览器 Basic Auth 弹窗。
- 公开注册关闭；当前只有原管理员可登录，普通账号即使启用也受发布限制。
- 最近代码验证：前端 199 项测试和构建通过；后端回归快照 260 项、最终 Zotero/认证/文件/打包专项 43 项及恢复/启动专项 14 项通过；插件接口与断线恢复模拟 13 项、打包校验 2 项通过。该数字不表示每次文档修改都重跑全仓库测试。
- 本次发布零模型冒烟 5/5，9 篇论文、12 条批注与 7 个 PDF 版本保留，研究运行数未增加，维护会话已撤销。公网管理员登录、Secure Cookie、PDF Range 读取、退出失效及匿名私有资源 401 已验证。
- 验证未开放普通账号或执行生产全量恢复。已登录账号管理页尚未完成浏览器人工逐项验收。

## 未完成与限制

统一知识条目、显式长期记忆审核/召回、OCR/图像导读、完整 kelip/Nature 材料链、导读历史版本选择、全局费用账本、固定时刻日报/周报、站外推送、共享协作角色与多 Web 副本均未完成。详细优先级与验收见 [后续计划](ROADMAP.md)。

论文库、会话持久化及向量检索不能直接等同于统一知识管理与长期记忆。精读能力以实际读取材料、证据和已适配工具为准。

## 文件管理首批交付

已实现文件与批注统一入口、版本上传和去重、默认切换与索引补偿、旧材料会话保护及带批注 PDF 下载。兼容迁移以真实文件哈希关联旧批注；资料缺失时明确保留未解析记录。验证情况见 [变更记录](CHANGELOG.md)。分类路径和父分类筛选已由 Zotero 交换迁移补齐；本批未完成完整分类树编辑器、跨版本智能批注迁移、扁平化导出和完整会话材料版本界面。

插件安装修复：0.1.1 补齐真实安装校验必需的更新地址，并用 Zotero 自身解析器确认清单有效与版本兼容；用户随后已完成安装与配对。当前升级包为 0.1.3。0.1.0 原包缺少该字段，不能使用此前的打包通过结果作为可安装证明。


当前插件 0.1.3 初步修复：已有条目保留分类、跨库关联保护、去除往返分类包装/同名嵌套、正文哈希查重、不同附件键复用、重复排队与领取映射幂等、子附件选择、失败队列隔离、文件可读与全文索引分离。历史疑似重复和人工分类未自动合并或删除；并非完整 Zotero 镜像同步。实际旧版记录出现过 180 秒上传超时，首批回归用隔离数据验证，不在用户研究库上创建测试论文。
