# Firework 使用指南

更新：2026-11-23。适用于业务迁移0026、身份schema3、Runner协议12、Zotero插件0.1.4。本文按实际操作组织，不保留旧批次的重复说明。部署见 [环境与部署](enviroment.md)，系统边界见 [架构](架构.md)，最新验收见 [交付说明](READING-CONTEXT-DELIVERY.md)。

## 1. 登录与首页

使用已初始化的管理员账号登录。公开注册关闭，默认仅允许原主管理员登录；管理员创建其他账号不代表已解除部署的登录限制。不同账号的论文、文件、会话、技能和模型凭据独立。

顶部提供读论文、前沿追踪、论文比较、定时任务和论文库管理。首页左侧是最近阅读、领域分类和相关会话，中央提供材料选择、任务输入与常用模板。点击左上角 **Firework** 返回阅读起始首页，保留已打开论文与阅读记录。

首次使用建议：**配置模型连接 → 选择额度 → 导入一篇PDF → 打开原文并发送小问题 → 按需触发批注或追踪**。原管理员可继续沿用已有连接。

右上角用户菜单提供模型连接、技能库、设置、Zotero、研究产物与知识库，以及当前页面共享入口。查看论文、选择模板、保存设置及浏览既有成果不会自动创建研究任务；发送问题、确认导读、普通智能体导入或启用调度可能产生模型用量。

## 2. 配置模型与任务额度

### 模型连接与测试

1. 用户菜单 → **模型连接**，或访问 `/#/settings/runner/connections`。
2. 选择供应商预设或自定义，填写名称、根地址、准确模型ID和Key。预设包括Anthropic、DeepSeek、MiniMax、阿里云百炼不同套餐、Kimi及自定义；按界面标明的地区/套餐核对，不能混用Key。
3. 当前执行需要Anthropic Messages兼容接口。纯OpenAI格式地址需兼容网关；模型名称按供应商实际要求填写，预设不包含凭据。
4. 设置图片能力、上下文容量与研究角色补充要求。能力默认未知，填写1,000,000不代表已验证1M，也不会自动修改模型能力。角色不扩大工具或文件权限。
5. 保存后可设为新会话默认，再选择测试方式。

| 操作 | 验证范围 |
| --- | --- |
| 配置预检 | 字段及本地约束，不调用模型 |
| 网络测试 | Runner检查端点可达，不发送Key；401/404等响应不能当成鉴权成功 |
| 最小模型测试 | 明确确认后发送固定“Reply with OK.”，最多输出32 token，检查实际文本流及结束；可能产生少量费用 |

测试结果绑定连接修订，编辑后旧结果显示过期。不会自动重试或改用其他模型；测试可取消，但已发给供应商的请求不能保证不计费。一次文本成功不能认证视觉、1M或完整Claude工具执行链。

Key加密保存且不回显。编辑留空保留原Key；普通复制不复制Key，更改地址/鉴权要重新填写。**添加模型**当前会复制为独立加密连接，后续凭据修改不联动。默认仅允许公网HTTPS，内网服务需维护者配置允许列表。

### 会话内切换

智能体输入区底部连接条显示当前绑定。新会话可选连接；已有会话切换通过分支预览，确认转移历史后建立新会话，不静默把旧会话改到另一供应商。执行中不能改变在途任务的配置。使用固定方案时，还需遵守方案绑定。

自定义连接与账号凭据隔离，不改部署机器全局Claude配置，不回退其他用户Key。原管理员legacy模式与自定义连接是不同路径。

### 任务额度

进入 `/#/settings/runner/budgets`，可复制、编辑预设并设置默认：

| 预设 | 推理轮次 | 单次输出token | 工具调用 | 时长 |
| --- | ---: | ---: | ---: | ---: |
| 快速问答 | 8 | 2048 | 4 | 180秒 |
| 标准研究 | 24 | 8192 | 24 | 1800秒 |
| 深度研究 | 40 | 16384 | 48 | 3600秒 |

这些预设关闭CLI估价金额守卫，其他保护分别生效。沿用Skill旧策略时仍可能有原金额限制。阅读输入区可为下一次发送选择额度，优先级为本次选择、账号默认、Skill策略；结构化导读另有输出要求。

额度不等于供应商实际账单硬上限；已提交任务保留原快照，失败不会自动重跑。费用账本、对账和累计账单专项不在当前建设范围。

## 3. 搜索与添加论文

从首页、论文标签 **＋** 或论文库的搜索/导入入口添加：

| 渠道 | 使用方式 |
| --- | --- |
| 本地PDF | 上传文件、选择分类，查看导入进度 |
| arXiv | 输入标识或链接，获取元数据与可获得全文 |
| DOI | 获取书目信息及可获得的公开全文 |
| 公开URL | 输入论文页面或PDF链接，按实际可用资源导入 |
| 前沿报告 | 批准候选论文加入论文库；项目进入项目库 |
| Zotero | 插件手动发送条目或分类，见第9节 |

普通导入会创建智能体任务，可能调用模型。提交成功不代表PDF已保存，需核对状态；只有元数据时补充全文，不能把书目当作全文阅读。点击没有PDF的论文会提示补全文，不进入空白纯智能体阅读页。

Zotero交换不调用研究模型，首次PDF可先阅读，全文索引稍后明确建立。

## 4. 论文分类、文件与版本

论文卡片显示预览图、题名、作者/单位和简要摘要；可按分类、关键词、阅读状态筛选并编辑元数据。来源未提供作者单位时可能缺失，不把候选信息当作已核验事实。

分类旁 **＋** 新建子分类，表单可选父分类或顶层；选择器显示完整路径，同父级不能重名。筛选父分类包含后代论文，数量去重。个人分类旁 **⋯** 可重命名、移动或删除整棵有效子树；不能移入自身/后代。分类回收站可恢复整树，原位置重名时需先解决冲突。删除分类不会删除论文、文件或会话。

Zotero来源分类显示同步标识，由同步维护；请在Zotero修改，或新建个人分类整理，避免重复来源树。跨端移动/删除传播尚未提供。

论文卡片 **更多 → 删除论文** 将论文移入回收站；可恢复原记录，文件、批注、版本、会话和同步关联保留。活动任务/导入期间拒绝删除；此操作不删除Zotero条目，也不是永久安全擦除。回收站论文恢复前不能执行新的研究任务。

在 **文件与批注** 或阅读工具栏 **文件 / 下载**：

1. 查看正文、补充材料、哈希、页数、版本、来源和索引状态。
2. 上传PDF为已有文档增加版本，或新建补充材料；旧文件不可变，相同内容可复用。
3. 明确设定默认阅读版本；活动任务期间不能切换。切换可能解析PDF并更新全文索引，不调用研究模型。
4. 保留旧版本和历史证据；旧会话不能静默换用新材料继续运行。

PDF版本上传上限50 MiB、300页，不支持加密PDF。历史版本可预览、下载及通过带version的阅读链接打开，位置按版本保存。内部标签仍按论文去重，同一论文多个版本并列标签尚未提供。扫描件没有自动OCR。

## 5. 多标签三栏阅读

从左侧点击论文直接进入原文阅读，恢复关联会话与位置。标签 **＋** 可选已有论文或导入，已打开论文切回原标签。关闭标签不删除论文或阅读记录。

- 左侧：目录、批注、导读、译文、信息。
- 中间：PDF原文；阅读工具栏位于PDF栏正上方。
- 右侧：当前论文关联智能体会话。

拖动两条分隔线调整宽度，左右面板可收起；布局、页码、缩放、辅助页和草稿会保存。切换标签不会自动重跑模型。

可复制的Hash地址表达资源，例如：

```text
/#/home
/#/reader/19?session=7&page=4&panel=notes
/#/reader/19?version=VERSION_ID&session=7&page=4&panel=translations
/#/frontier/topics/6/reports/REPORT_ID
/#/library?collection=3
/#/research/artifacts/ARTIFACT_ID?revision=2
```

示例中的ID需替换为有权访问的真实资源。明确链接优先于旧阅读状态；旧session_id链接兼容。无权访问或明确会话失效时显示错误，不静默打开另一会话。单条批注的深链自动聚焦尚未提供，下载地址不使用Hash。

## 6. 讨论、比较、模板与图片

**Enter发送，Shift+Enter换行**；中文输入法确认候选不会误发送。输入区 **技能与模板** 中，技能来自已发布且当前功能可用的技能库；提示词模板先填入输入框，修改后再发送。打开菜单和选择模板不调用模型。

可将原文选区与文字、图片一起提交。图片支持上传、粘贴、拖入、预览及移除。普通讨论最多3处原文引用、3张图片，PNG/JPEG单张不超过5 MiB，并有限定尺寸。连接未声明支持视觉时拒绝图片；声明支持仍需真实模型支持。

右侧记录独立滚动，输入区可通过工具行按钮最小化。连接条位于输入区底部，“模型与任务额度”收纳高级设置。阅读旧回复时新内容不会强制拉回底部，可点 **↓ 最新** 或新内容提示返回。

正文随智能体部分消息逐段显示，重连恢复已保存正文；不保证所有供应商逐token返回。结束原因与部分结果以实际Run状态为准，关闭浏览器不等于取消任务。

论文比较从顶部或模板进入，选择多篇论文并保留独立比较会话。会话和Markdown导出是研究记录，不会自动全部写入长期记忆。

## 7. 按需生成导读与批注

打开论文不会自动执行。左侧 **批注** 页可触发 **自动批注**；兼容的输入区阅读辅助入口也可使用。

1. 选择已发布兼容Skill，检查目标、材料页数和重点数。
2. 明确确认后运行。当前结构化导读最多6页、10个重点，默认6个重点；不等于全文深读。
3. **导读**展示概要、贡献、边界和阅读路线；**批注**统一展示高亮、备注、手绘与AI重点解释。
4. 高亮可继续写备注；AI原始批注采纳后成为可编辑个人副本，后续生成不覆盖。

AI标记可移除/恢复、图层可隐藏。已有导读的重点标记在批注页管理；显示开关位于导读中。历史导读入口可查最近30条记录及失败信息，导出带来源版本的Markdown，不改变当前图层。

译文保留原文与文件身份，点击定位时核对原PDF。唯一匹配才强调具体段落；重复引句结合明确选区，无法核验时仅跳页。旧版本证据打开原文件，不把旧坐标套到当前PDF。翻译失败不影响移除记录；撤销恢复和明确重试继续可用。

本机回传的reading/guide产物也可显示在导读；外部AI批注进入批注页。当前结构化导读不自动读取图片、OCR或官方代码；深读研究能力由用户维护的Skill提供，结果展示按兼容契约接入。

## 8. 前沿追踪与定时任务

新建主题，可选领域、关键词、作者、团队、目标、排除项、来源、分类及兼容Skill。新主题默认暂停，建议先小范围手动执行，再启用间隔调度。

报告按时间堆叠，最新在上；支持展开历史、已读及导出。发现项与当前账号已有资料及跨主题结果去重，区分新增、更新和已知；元数据发现不等于完成全文审查。

论文和项目先待批准，批准时选择分类；重复批准不重复入库。也可忽略或恢复候选。本机研究可使用同一报告回传契约，保留外部来源和待批准流程，不自动推进服务器研究游标。

持续调度会创建后续模型任务。当前支持间隔、启停和状态，不是完整日历/Cron调度。作者/团队消歧与研究判断由Skill承担，报告语义差异等高级展示尚需按实际输出适配。

## 9. Zotero 手动双向交换

插件0.1.4，声明兼容Zotero 10.0.6–10.x。从 **Zotero集成** 下载XPI，在Zotero插件管理器从文件安装；升级已有设备无需重新配对。

### 配对

1. Zotero的Firework工具菜单中开始配对，填写自己的Firework HTTPS地址。
2. 网页输入插件显示的8位配对码，核对设备并确认授权。
3. 回到插件完成领取。无需提供网页登录密码；设备授权可撤销，凭据30天到期。

### Zotero → Firework

发送选中文献，或从分类右键发送当前分类及子分类。先确保PDF已下载到本地，附件缺失时补齐重试；状态在插件查看，不会连带重跑所有历史失败记录。

### Firework → Zotero

网页选目标设备和论文加入队列；Zotero选目标库/分类，使用Firework接收入口确认。失败后在网页重试，再从同一目标库接收。配对成功不代表客户端在线，两方向有独立队列。

当前交换书目、分类路径、标签与原PDF；补充材料和历史版本作为附件。稳定来源键、精确标识和文件哈希用于去重，元数据冲突不静默覆盖。分类/标签增量加入，不传播删除或移动。

**尚不回流**Firework导读/审查子笔记、原生批注、会话和阅读状态，也没有官方Connector自动接收。PDF本来内嵌的批注随文件保留。收到PDF后可阅读；需要全文搜索时明确点击建立索引，不调用研究模型。

## 10. 批注下载与 Skills

文件面板按版本及来源选择下载原始PDF、带批注PDF或批注Markdown。带批注PDF在副本写入有效高亮、备注与手绘，不改原件；已删除或不符合有效AI图层条件的批注不叠加。不同PDF阅读器对外观支持可能不同。

跨版本批注可在文件管理中预览迁移，唯一引句匹配后明确确认复制；歧义、手绘或无法核验的内容不自动搬移，原记录保留。

技能库支持ZIP预检/安装、分类、标签、显示名、版本、启停、功能可见性和审计。也可 **＋新建Skill** 编写指令，保存草稿后发布新版本；编辑内置指令会创建独立技能。显示名不替代稳定技能身份，旧Run保留其执行版本。

为技能设置对话、导读批注、前沿等可用范围；入口仍检查所需工具和输出契约。固定执行方案可能进一步限制选择。安装不执行任意脚本，也不代表研究质量已验证；点击最小执行验证才创建真实模型任务。详见 [Skills开发](SKILLS.md)。

## 11. 常见问题

| 现象 | 处理 |
| --- | --- |
| 浏览器密码框后又出现网页登录 | 检查残留网关Basic Auth，当前使用应用认证 |
| 连接保存成功但任务失败 | 先网络测试，再明确触发最小模型测试；检查协议/Key/模型，并查看真实Run失败原因 |
| 修改连接后旧会话不能发送 | 旧会话固定修订，通过底部切换预览建立新分支或新会话 |
| 触及金额、轮次或时长限制 | 看实际额度快照；各限制独立，调整后手动重试，不自动重复计费 |
| 导读或译文不能精确定位 | 检查PDF版本、引句歧义和文字层；无可靠文字时只能页级定位 |
| 新版本看不到旧批注 | 先查看原版本，必要时预览并确认复制，不能直接复用旧坐标 |
| Skill已安装但入口不显示 | 检查发布版本、启用状态、功能可见性、工具及输出兼容性 |
| 本机MCP看不到页面 | 检查context:read、页面共享、窗口ID和45秒时效；论文仍需独立读取权限 |
| 本机写回超时，是否应重跑研究 | 先按client_job_id查回执或以原幂等键重试相同内容，不重新调用模型 |
| 本机回传的PDF为什么没成为正文 | 研究附件上传与正文版本导入是不同功能；外部正文版本管理尚未完整开放 |
| 重启后任务中断 | 查看已保存部分结果，再明确决定恢复；不会自动重跑付费请求 |
| Zotero疑似重复 | 核对来源键、目标库和PDF哈希，不自动合并/删除研究记录 |

## 12. 原生记录、隔离终端与运行检查

阅读右栏 **原生记录** 展示当前绑定Claude历史，可分页、检查新记录及继续会话；不扫描宿主其他未绑定日志，不显示思考内容、工具参数或图片原始编码。

启用原生容器功能后，可打开 **隔离终端** 创建独立原生分支。主题、目录信任和工具权限提示由用户在终端处理，尚无结构化权限卡片。原生分支不复制旧聊天，也不自动挂载注册Skill或第三方MCP。文件范围受限，可下载工作文件或收录成果。

关闭网页不会停止终端。其他窗口接管需等待控制租约释放；Runner重启会停止遗留容器并标记中断，必须明确恢复，不重放请求。若入口不可用，请维护者核对固定CLI镜像及Runner配置。

Run记录可进入检查页查看事件、材料、配置、部分结果和失败原因，导出脱敏调试包；分支先预览转移内容再确认。实现边界见 [原生交互与研究平台](RESEARCH-PLATFORM.md)。

## 13. 研究产物与知识库

用户菜单 → **研究产物与知识库**。新托管Run的非空结果会收录为产物；历史结果需明确点 **收录已有研究结果**，按来源去重，不自动发布知识。

产物可关联论文、固定PDF证据、附件和来源Run，编辑保存为新修订，支持Markdown下载。失败/取消任务有正文时保存为部分结果，不能当作完整结论。

可从产物提取知识候选，区分原文事实、研究推断和个人观点。审核后发布；原文事实需已核验引用。来源变化会暂停默认召回，可审核、撤销或重新处理。目前召回为文本检索，不是自动语义长期记忆；聊天不会未经审核全部进入知识库。

## 14. 执行方案与本机 MCP

### Web服务器执行

在 **执行方案与MCP** 组合Skill、连接、额度、角色补充要求与内置工具权限。新任务选择方案并预检后发送，旧会话固定绑定。此页面尚不能添加任意第三方MCP服务。

### 本机研究后回传

1. 在 **外部智能体接入** 下载最新通用Skill ZIP，完整解压。
2. 创建范围最小的外部授权，设置有效期和可选论文白名单；保存到本机私有文件，macOS/Linux权限设为600，不将令牌贴到对话或提交Git。
3. 在支持stdio MCP的本机智能体中注册包内服务。使用Python 3，无第三方依赖；替换以下路径和站点：

```json
{
  "mcpServers": {
    "firework": {
      "command": "python3",
      "args": ["/absolute/path/firework-paper-ops/scripts/firework_mcp.py"],
      "env": {
        "FIREWORK_URL": "https://your-firework.example",
        "FIREWORK_TOKEN_FILE": "/absolute/path/private-token",
        "FIREWORK_UPLOAD_ROOT": "/absolute/path/research-files"
      }
    }
  }
}
```

4. 先读取获准论文/版本/页面，在本机运行自己的Skill；附件上传后提交成果及引用，保留稳定request_key和client_job_id。
5. 核对回执中的产物、批注、翻译ID和链接。重复相同任务返回原回执；同job不同内容被拒绝。网络结果未知时先查询，不能换键盲目新增。

上传/下载限定在所配置研究目录，令牌文件禁止上传。上传研究附件上限30 MiB，不等于向论文库导入正文PDF。附件先上传，成果及批注/译文投影作为同一事务提交；更新既有产物需expected_revision。

本机结果标记为external与调用方声明的Skill身份，不伪造服务器Run，不重复调用服务器模型。reading/guide进入导读；批注/翻译进入对应辅助页；前沿报告进入时间线和待批准队列；知识仍为候选。

| 操作 | 主要权限 |
| --- | --- |
| 论文材料 / PDF下载 | papers:read / files:read |
| 成果、附件与回执 | artifacts:write / artifacts:read |
| 批注与翻译提交 | annotations:write，另需成果写入权限 |
| 前沿报告 | frontier:read / frontier:write |
| 知识候选 / 已发布召回 | knowledge:write / knowledge:read |

无论文白名单的前沿授权与限定论文的阅读授权分开配置。完整载荷、工具与REST示例见 [MCP说明](../plugins/agent-skill/firework-paper-ops/references/mcp.md)、[前沿回传示例](../plugins/agent-skill/firework-paper-ops/references/frontier.md) 和 [外部API](EXTERNAL-AGENT-API.md)。

### 共享当前页面

用户菜单显式开启 **共享当前页面给本机智能体**，本机使用context:read列出窗口并指定context_id。读取具体论文仍需papers:read；多个窗口不能猜测目标，读取资源时传expected_revision，切页后按新修订重新确认。

共享默认关闭；前台心跳15秒，45秒过期，后台窗口不可作为有效当前页面。关共享/登出后拒绝读取。不共享输入草稿、API设置、图片或系统其他窗口。

PDF选区另行显式分享，需context:selection，最长5分钟。分享只授权读取快照，不提供页面控制。关闭页面共享不会自动撤销独立成果写入权限，需要时在外部接入页撤销令牌。
