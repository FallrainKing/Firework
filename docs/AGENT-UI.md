# 智能体界面与会话管理

更新：2026-11-21。

## 参考与适用边界

参考 [Corral](https://github.com/ihainan/corral) 的智能体会话组织。核对参考版本 `d9c88d346832e781bb925c7bbb59682c150428cb` 的 `web/src/pages/AgentsChat.tsx` 与 `web/src/terminal/Conversation.tsx`：会话列表、任务状态、独立输入区、可折叠活动记录，以及回答和执行过程的视觉分离。本次为 Firework 原有 Vue 组件的独立实现，未复制 Corral 源码或引入其依赖。

Corral 管理 SSH/终端中的智能体，Firework 管理论文、会话与受限 Runner 任务。这里借鉴交互组织，不接入终端控制、SSH 主机或终端按键注入。既有账号隔离、按 Skill 授权的研究工具、费用校验和明确触发规则继续适用。

## 本轮已实现

### 阅读区

- 在右栏增加“完整会话 / 阅读结果”。完整会话保留执行详情与工具记录；阅读结果隐藏工具和诊断折叠项及轮次用量，保留问题、回答、原文引用、图片和失败信息。
- “你 / 智能体”区分问题与回答；智能体回答标明实际 Run 模型，不把当前配置冒充历史执行模型。
- 工具过程收为一行，显示调用次数与开始/结束时间计算的耗时。缺时间显示“未提供”，不制造精确运行指标。
- 提供“↓ 最新”入口；延续独立结果滚动和底部输入区，上翻阅读不被新内容打断。切换显示模式不创建 Run、不删除历史、不改变会话关联。
- 失败和取消仍可以重新编辑；阅读结果模式不隐去错误，也不将部分输出伪装成完成结果。

### 会话管理

- 论文库管理 → 任务会话，增加全部、进行中、需检查、已完成筛选，以及当前搜索/分类结果内的数量。
- 进行中包含 queued/running；需检查包含 failed/cancelled，**不代表待审批或未读状态**。
- 排序优先为进行中、需检查、置顶、其他，同组按更新时间排列；记录只重新排序，不改数据库中的置顶和状态。
- 会话卡片展示结果预览、轮次数、状态和未发送草稿标记，可手动刷新列表。切换后清除上一会话的运行列表，防止新会话载入时暂时展示旧回答。
- 列表状态来自持久化的 last_status；打开会话后继续轮询在途 Run。没有新增全局后台轮询或浏览器通知。

### 配置管理

设置页用管理卡片集中连接模型、任务额度和技能库。MCP 明确标注当前由 Runner 提供、独立管理页尚未交付，避免展示无效配置入口。模型、额度和技能仍走既有账号作用域的服务，不新增共享配置。

## 接口与数据复用

继续使用 `sessionsApi.list/get/runs/update`、`agentApi.getRun/createRun/cancelRun` 和既有连接、额度、技能 API；本轮不改数据库、Runner 协议和 API 契约。筛选和显示模式属于组件状态；刷新恢复默认“完整会话 / 全部”，论文页码、布局、草稿仍由原有工作区存储恢复。

## 后续实施顺序

1. 在服务端为会话列表提供可靠分页、状态聚合和过滤；若加入全局活动中心，先统一活动源，不能为每张卡片单独轮询。
2. 增加按账号持久化的显示与输入偏好，补齐输入法、移动端换行、快捷键和跨标签草稿一致性。
3. 构建 MCP 配置中心与执行方案，将模型、额度、Skill 版本和工具权限绑定为可审计快照；权限确认必须来自真实任务状态。
4. 后续再增加已读游标、待处理计数与通知。没有持久化游标时不把“已完成”等同于“未读”。

## 验收

- 长回答和短窗口仍可滚动，输入框与发送按钮可达；改变显示模式不调用模型。
- 结果模式保留失败、部分输出、图片和引用；恢复完整会话可再次检查工具与运行信息。
- 进行中/需检查排序和筛选准确，数量口径明确，不改变原始状态与分类。
- 配置入口可达；未交付能力有明确边界，不显示可操作的假入口。
- 前端单元测试及类型检查/构建通过。测试使用模拟 API，不以此声称模型和第三方 MCP 已真实验证。
