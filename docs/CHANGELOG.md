## 2026-11-20

- 修复 Zotero 0.1.0 安装失败：清单漏填当前 Zotero 要求的 `applications.zotero.update_url`，真实控制台报 `Invalid XPI`。发布插件 0.1.1，生成 HTTPS 更新清单（含版本、兼容范围、下载地址和 SHA-256）；缺少必填字段时构建立即失败。
- 新版清单经本机 Zotero 10.0.6 的 `AddonManager.getInstallForFile` 解析返回 error 0 / compatible true；旧包返回 error -3。仅解析并取消，没有替用户安装或授权插件；交换操作仍待真实配对后验证。新增 2 项打包测试，插件模拟测试共 7 项，网页授权测试 2 项及构建通过。
- 旧版下载路径兼容返回修复后的安装包，网页改为明确下载 0.1.1；同时显式声明启动沙箱的哈希接口别名。

- Zotero P0/P1：提供可构建的 XPI、网页设备核对/授权/撤销、手动书目/分类/标签/PDF 交换和出站队列。
- 业务迁移 0015 与身份 schema 2；保留既有分类编号，支持同父分类唯一、路径展示与父分类筛选。来源映射、文件哈希、预分配条目键与可重试回执减少重复，人工修改冲突暂停处理。
- 手动传输不触发研究 Agent；首个正文仍复用现有 PDF 解析和本地嵌入。原生批注、会话、阅读位置和 Connector 自动采集未在此批实现。
- 验证：后端完整回归 256 项，最终相关专项 37 项；前端 198 项及构建；插件 6 项模拟测试，含回执丢失后不重复创建条目/PDF。生产研究库副本迁移保留 9 篇论文、12 条批注、7 个版本和既有分类关系，完整性与外键检查通过。
- `b97000e` 已发布，公网集成页与 XPI 下载、匿名隔离、PDF Range 及五步冒烟通过；研究运行新增 0。发布前后成套备份保留，维护会话已撤销。
- 插件目标 Zotero 10.0.6–10.x，已核对本机 10.0.6 的公开实现；尚未在真实客户端安装、授权或完成双向端到端验收。

- 首批论文文件管理：不可变正文版本、补充材料、默认阅读版本及文件哈希去重。
- 新增论文库“文件与批注”和阅读工具栏“文件 / 下载”入口；分版本查看批注，导出原件、标准批注 PDF 和 Markdown。

### Product

- 项目对外名称统一为 Firework，保留已有部署目录与服务标识以兼容资料和运维。
- 多论文标签、可调三栏阅读、原生会话恢复、模板与图片输入。
- 多来源论文导入、分类管理及前沿发现、去重、时间线报告和审批。
- 明确触发的 Skill 导读与批注，核验原文证据后渲染；打开论文不自动运行。
- 上传 ZIP 管理动态 Skills、版本、分类和受限工具。
- 使用 Marked 与 DOMPurify 统一渲染 Markdown。

### Authentication and operations

- 独立身份库、管理员账号管理与隔离研究空间；公开注册关闭，当前仅 primary admin 可登录。
- 统一为 HTTPS 应用网页登录，取消重复的网关 Basic Auth。
- 应用与宿主 Runner 使用协议 5；备份包含身份库、账号空间及各向量集合，恢复后撤销浏览器会话。
