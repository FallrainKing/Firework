## P1：前沿质量与成本

- 增加作者/团队实体消歧和噪声筛选，保留原查询、来源和排除原因。验收：相关性改善可量化，身份疑似合并有人工确认。
- 增加跨主题总金额账本、可见剩余额度与关闭策略。验收：费用未知不为零，总限额不因主题并发绕过。
- 将间隔调度扩展为时区明确的固定时刻/周报。验收：时区与夏令时明确，同窗口幂等，暂停可停止后续触发。
- 增强来源分页、报告版本与项目—论文关系。验收：跨轮结果不遗漏/重复误入库，已知更新与新发现分开，关系有来源。

## P2：统一知识与长期记忆

从已确认的导读、批注、报告和会话中提取候选知识条目，保存来源论文、文件版本、页码/证据、Run 与 Skill 版本。采用候选→审核→发布→更新/撤销流程，避免把未经确认的模型文字直接记为事实。

验收：可跨任务检索并追溯到原文；能区分作者主张、证据和个人观点；去重、冲突、更新和删除规则明确。会话延续和向量检索不代替上述验收。

## P2：规模与集成

多账号和独立数据空间已实现，当前限原管理员登录且注册关闭。开放普通账号、共享库与协作角色、队列外置、多 Web 副本、分布式调度和站外推送需要单独规划。当前保持单 worker；消息渠道必须明确授权，不将启用追踪等同于允许向外部账号发送内容。

## 实施顺序

先补可恢复性和运行模板，再优化阅读材料/版本，随后前沿质量与全局成本，最后统一知识和规模化。每批沿用：明确范围→接口/迁移→隔离验证→备份→同步发布→零模型冒烟→一次必要最小真实验证→文档与 Git。已完成能力不重复列入待实现范围。
