# Firework 设计语言：安静的研究工作台

实施：2026-11-21。采用已选定的方案 A，视觉参考 [Linear 的内容优先层级](https://linear.app/now/behind-the-latest-design-refresh) 与 [Spectrum 的专注原则](https://spectrum.adobe.com/page/principles)。本项目独立实现样式，沿用 Vue、现有组件和工作流程，不引入外部字体或新 UI 框架。

## 核心原则

正文和研究结果优先；导航与元数据降低视觉权重。通过对齐、留白和底色表达层级，浮层才使用明显阴影。控件保持一致尺寸和行为，状态必须同时包含文字，保留焦点、错误、任务执行提示和可恢复删除确认。

## 设计变量

定义位置：`frontend/src/shared/theme/tokens.css`。

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 内容面板 `--bg` | `#FFFFFF` | `#202328` |
| 工作区/导航 `--surface` | `#F7F8FA` | `#191C20` |
| PDF 画布 `--canvas` | `#ECEEF1` | `#121519` |
| 正文 `--text` | `#20252B` | `#E6E9ED` |
| 辅助文字 `--text-muted` | `#626B75` | `#A6AFB9` |
| 强调 `--accent` | `#237565` | `#83C9B4` |
| 强调面文字 `--on-accent` | `#FFFFFF` | `#152A23` |
| 分隔 `--border` | `#E2E5E9` | `#353A42` |
| 焦点外的强调边界 `--border-strong` | `#C7CDD4` | `#59616C` |

常规圆角 6px、面板圆角 10px；间距使用 4/8/12/16/24/32px。危险操作用 `--danger` / `--danger-soft`，警告用 `--warning`，不能与选中或执行中混淆。PDF 页面保留白底原稿，不随主题反相。

## 排版与组件

- 使用系统中英文字体；界面基础字号 14px，常规控件 13px，关键辅助文字不低于 12px。阅读 Markdown 15px、行高 1.8，长表格和代码仍独立横向滚动。
- 桌面基础按钮使用 6px × 12px 内边距，控件按工具栏需求紧凑排列；粗指针设备按钮至少 40px 高。
- 普通按钮轻边框、中性悬停；主操作墨绿色；选中使用淡色背景。深色模式的主按钮文字用独立反差色，不沿用白色。
- 键盘焦点采用明确的 2px 轮廓。减少动态效果偏好开启时关闭动画和过渡；运行状态仍保留文字。
- 菜单与弹窗采用中性内容面和统一浮层阴影。论文菜单继续挂载到 body，避免卡片裁剪，不为本轮视觉调整改变其定位和删除确认流程。

## 页面落实

| 页面 | 表达 |
| --- | --- |
| 全局导航 | 56px 桌面顶栏、较小品牌字、轻量选中背景；窄屏保留可横滚导航 |
| 首页 | 更舒展的欢迎区域、清晰标题、白色任务输入区和轻量模板卡片 |
| 论文库 | 中性分类树、白色资料卡、适当增宽卡片、减少胶囊装饰；保留紧凑列表和回收站 |
| 阅读区 | 紧凑圆角论文标签、白色工具栏、灰色画布、独立滚动的三栏 |
| 智能体会话 | 问题使用淡灰底，回答以正文排版；轮次用轻分隔替代重复边框；进度与额度可查 |
| 设置与 Skills | 白色管理面板统一圆角和边界，错误使用语义颜色 |
| 前沿追踪 | 保留时间线结构，报告使用白色内容面 |

## 验证边界

数值计算检查浅色正文、辅助文字、主色及深色正文、辅助文字、主按钮六组常规文字对比度，均超过 4.5:1；这是指定组合的检查，不代表完整无障碍认证。功能验证继续使用现有前端回归和类型检查/构建；发布后使用已有内容检查浅色、深色、首页、资料库、阅读与长回答，不为视觉核验产生新的模型任务。

后续新增页面必须复用语义变量；不要在组件里写固定白色主按钮文字或临时加大层级。视觉更新不修改会话、论文、删除、认证或智能体调用契约。
