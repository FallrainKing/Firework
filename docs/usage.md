# Firework 使用指南

更新：2026-11-21。适用于业务迁移 0018、Runner 协议 7。系统职责与技术细节见 [架构](架构.md)，安装维护见 [环境与部署](enviroment.md)。

## 1. 登录与首页

使用已初始化的管理员账号登录。当前公开注册关闭，默认只允许 primary admin 登录；管理员可以管理其他账号，但启用普通账号不等于解除部署的登录限制。各账号的论文、文件、会话和配置独立。

首页顶部依次为读论文、前沿追踪、论文比较、定时任务、论文库管理。左侧显示最近论文、领域分类和相关任务；中央提供欢迎引导、研究输入和模板。右上角用户菜单提供模型连接、技能库、Zotero 集成、账号设置与退出。

建议首次使用顺序：**配置模型连接 → 选择任务额度 → 导入一篇 PDF → 阅读并发送一条小问题 → 再按需启用导读或追踪**。原管理员也可保留原有连接。

## 2. 配置模型与任务额度

### 模型连接

1. 用户菜单 → **模型连接**，或打开 `/#/settings/runner/connections`。
2. 填名称、API 根地址、准确模型名称和 Key，按服务商要求选择 x-api-key 或 Bearer。
3. 当前需要 Anthropic Messages 兼容接口。纯 OpenAI 格式地址需要兼容网关，不能直接保证可用。
4. 图片能力默认未知；只有确认服务商支持时才声明支持。上下文最多可声明 1,000,000 token，但不会因此自动启用模型能力或改变模型名称。
5. 可填写研究角色补充要求，例如优先引用原文、明确实验依据。角色不会扩大工具或资料访问权限。
6. 保存后选择该连接并点击 **保存默认连接**，用于新会话。配置预检不调用模型，也不验证服务可达性、视觉或长上下文的真实支持。

Key 加密保存且不回显。编辑留空保留旧 Key；复制连接不复制 Key；更改地址或鉴权方式要重新填写。默认仅允许公网 HTTPS，内网服务需维护者配置允许列表。

已有会话保持原连接。修改、停用连接或切换服务商后，请新建会话，不要期待旧会话自动切换。独立账号必须使用自己的连接，不会借用管理员 Key。

### 任务额度

进入相邻的 **任务额度** 页，或 `/#/settings/runner/budgets`：

| 预设 | 推理轮次 | 单次输出 token | 工具调用次数 | 执行时长 |
| --- | ---: | ---: | ---: | ---: |
| 快速问答 | 8 | 2048 | 4 | 180 秒 |
| 标准研究 | 24 | 8192 | 24 | 1800 秒 |
| 深度研究 | 40 | 16384 | 48 | 3600 秒 |

三种新预设均关闭 CLI 估价金额守卫，但保留其他限制；可以复制并编辑自定义额度。**沿用各 Skill 原有额度**仍可能包含 $0.10/$0.20 等金额上限，保存新默认后才改变后续任务。

阅读输入框可以为下一次发送选择额度；优先级为本次选择、账号默认、Skill 原策略。自动导读和追踪也使用账号默认额度。快速问答不满足结构化导读的输出要求，预检会提示。

CLI 金额只是估算，不能保证服务商实际账单上限；单次输出 token 也不是整轮累计 token。历史或排队任务保留提交时的额度，不因修改预设而扩大。失败后不会自动重新计费执行。

## 3. 搜索与添加论文

通过首页或论文选择器的 **搜索 / 导入论文** 入口添加资料。

| 渠道 | 操作与结果 |
| --- | --- |
| PDF 上传 | 选择本地 PDF 和分类，跟踪导入任务状态 |
| arXiv | 输入标识或链接，获取书目信息及可获得全文 |
| DOI | 输入 DOI，获取元数据及可获得的公开全文 |
| 公开 URL | 输入论文页或 PDF 链接，按来源实际可用资源导入 |
| 前沿发现 | 查看报告候选，明确批准进入论文库或项目库 |
| Zotero | 配对后手动发送选中文献或分类，见第 9 节 |

普通导入流程会创建智能体任务，可能产生模型用量。提交成功不等于全文已保存，需检查完成状态。没有公开全文时可先保留书目信息，再补充 PDF；系统不会将元数据冒充全文阅读。

Zotero 手动交换是独立路径，不调用研究模型；首次 PDF 可先阅读，全文索引稍后明确建立。

## 4. 论文分类、文件与版本

论文库卡片显示预览图、题名、作者/单位和简要摘要；可按关键词、分类和阅读状态筛选，缺失元数据可编辑。

分类树支持父子层级。点击分类旁的 **＋** 创建子分类，也可在表单选择父分类或顶层。分类选择器显示完整路径；同父级不能重名，不同父级可以同名。筛选父分类包含后代论文，数量按论文去重。当前没有分类重命名、移动、删除与跨端镜像操作。

通过卡片 **文件与批注** 或阅读工具栏 **文件 / 下载** 管理正文、补充材料和版本：

1. 查看文件来源、哈希、页数、可用状态及是否已建立全文索引。
2. 上传 PDF 到已有文档以增加版本，或新增补充材料。旧文件不覆盖，相同内容可复用。
3. 明确选择 **设为默认阅读版本** 后，新正文才用于三栏阅读与检索；有在途任务时不能切换。
4. 默认切换可能解析 PDF、建立嵌入和更新索引，但不调用研究模型。失败应先查看原因，不能只凭按钮点击判断完成。
5. 旧材料会话保留历史，不能静默使用新版继续讨论；重新进入当前版本阅读后使用相应会话。

PDF 版本上传上限为 50 MiB、300 页，不支持加密文件。旧版本可以在管理面板预览和下载；三栏智能阅读使用默认正文。扫描件无可提取文字时，不会自动获得 OCR。

## 5. 多标签三栏阅读

点击左侧论文直接打开 PDF，恢复阅读位置和对应会话。没有 PDF 时显示补充全文入口。

- 标签栏在三栏上方，**＋** 可选已有论文或导入；已打开的论文切回原标签，不重复打开。
- 左侧显示导读、目录、批注、高亮、译文和信息；中间显示 PDF；右侧显示关联智能体会话。
- 拖动分隔线调整宽度，左右面板可收起。每篇论文保留页码、缩放、辅助区、会话和草稿，工作区保留布局。
- 关闭标签只关闭工作区页面，不删除论文或阅读记录。

页面书签使用 `/#/`，例如 `/#/reader/19?session_id=7`。旧阅读链接会转换，登录后返回原目标；文件下载地址不使用 Hash。

## 6. 讨论、比较、模板与图片

Enter 发送、Shift+Enter 换行；中文输入法确认候选不会误发送。模板先填入输入框，修改后再发送。可以选中原文作为上下文，上传、粘贴或拖入图片，发送前预览或移除。

普通讨论最多带 3 处原文上下文和 3 张图片；PNG/JPEG 单张不超过 5 MiB，并有尺寸限制。自定义连接必须声明支持图片，否则拒绝提交；声明支持仍需实际模型具备视觉能力。

右侧回答与会话记录独立滚动，底部输入框与发送按钮保持可用。展开会话详情会在记录区内显示；“模型与任务额度”默认折叠，导读配置、图片与引用在受限高度的辅助区内滚动。位于底部时新回复跟随；上翻阅读历史时不强行跳走，点击“新内容，回到底部”可返回最新。

新会话首轮可在输入区选择模型连接；有运行记录后保持绑定。每次发送仍可另选任务额度。执行详情显示连接/版本、模型、Skill、工具、用量和结束原因；未完成输出按部分结果处理，可重新编辑后手动发送。

论文比较从顶部 **论文比较** 或任务模板进入，选择多篇论文并保留独立比较会话。会话历史和导出 Markdown 是研究记录，不会自动成为跨任务长期记忆。

## 7. 按需生成导读与批注

打开新论文只显示建议，**不会自动执行**。

1. 在输入区选择“自动批注”建议，检查 Skill、阅读目标、材料页数和重点数量。
2. 点击 **确认生成批注**，才执行技能。
3. 当前最多选择 6 页、10 个重点，默认 6 个重点；这是受限材料导读，不是全文精读。
4. 完成后查看总结、阅读路线、重点、重要性理由、解释、覆盖范围和未知内容。
5. 原文精确引文能唯一定位时显示高亮；否则显示页级笔记，避免错误标注。

AI 图层可隐藏，标记可移除/恢复；“采纳为我的批注”生成个人副本，之后生成不覆盖它。查看既有解释、切页和隐藏图层不调用模型。相同材料与配置优先复用；失败记录可移除，但重试仍需明确确认。

当前结构化导读不使用图片、OCR 或官方代码材料。选择“阅读论文”确认后执行的是普通阅读 Skill，会话与结构化导读任务分开。

## 8. 前沿追踪与定时任务

新建主题，可选领域、关键词、作者、团队、研究目标、排除项、来源和分类。新主题默认暂停。建议先手动执行小范围任务，确认来源与额度后再启用间隔调度。

报告按时间堆叠，最新在上；可展开历史、标记已读和导出。结果与当前账号已有资料及跨主题发现去重，区分新增、更新和已知内容；失败、截断和覆盖不足会显示。

候选论文和项目先待批准，用户可批准、忽略或恢复；批准时选择分类。重复批准不会重复入库，论文与开源项目分开管理。发现元数据不等于完成全文审查。

持续调度会反复创建模型任务。当前支持间隔运行、启停及状态，不是完整日历/Cron 调度，也没有所有主题共用的实际账单硬上限。

## 9. Zotero 手动双向交换

当前插件 **0.1.4**，声明兼容 Zotero **10.0.6–10.x**。从用户菜单 **Zotero 集成** 下载 XPI，通过 Zotero 插件管理器从文件安装，已有设备升级无需重新配对。

### 配对

1. 在 Zotero 的 Firework 工具菜单选择配对，输入自己的 Firework HTTPS 地址。
2. 网页输入插件显示的 8 位配对码，核对设备并确认授权。
3. 回到 Zotero 完成领取，刷新网页设备列表。插件不需要网页登录密码；授权可撤销，设备凭据 30 天到期。

### Zotero → Firework

选中文献后发送，或在分类上选择 Firework 发送当前分类，包含子分类。先确保 PDF 已下载到本地；附件缺失时补齐后重试。发送状态在插件侧查看，新发送不会连带重跑旧失败记录。

### Firework → Zotero

网页选择目标设备与论文，加入接收队列；Zotero 选择目标库/分类，使用 Firework 接收入口并确认。失败后在网页重试，再从同一目标库接收。已配对不表示客户端在线，两个方向有各自队列与状态。

当前交换书目、分类路径、标签和原始 PDF，历史版本与补充材料作为附件。稳定来源、精确标识和内容哈希用于复用；元数据冲突暂停处理，不自动覆盖人工编辑。分类/标签只增量加入，不跨端传播删除或移动。

Firework 原生批注、导读、会话、阅读位置和 Connector 自动采集尚不交换。PDF 本来内嵌的批注仍随文件保留。收到 PDF 后可直接阅读，需全文检索时在文件面板点击 **建立全文检索索引**，不会调用研究模型。

## 10. 批注下载与 Skills

文件面板的批注页可选文件版本及来源，下载：

| 格式 | 内容 |
| --- | --- |
| 原始 PDF | 保存的原件，保留原件本来包含的批注 |
| 带批注 PDF | 在副本写入该版本有效的高亮、备注与手绘；不修改原件 |
| 批注 Markdown | 批注文本和对应资料信息 |

已删除、未发布或隐藏的 AI 批注不会再次叠加。不同版本不自动搬移批注；历史无法关联原件的批注显示未解析状态。导出不调用模型，不同阅读器对批注外观的支持可能不同。

技能库支持上传 ZIP、预检、分类、标签、版本、启停和审计。安装不自动执行脚本，也不代表效果通过。“最小验证”会创建真实模型任务。自定义导读技能还须具备规定工具与输出条件，见 [Skills 开发](SKILLS.md)。

## 11. 常见问题

| 现象 | 处理 |
| --- | --- |
| 浏览器先弹账号密码，再出现登录页 | 让维护者检查是否残留网关 Basic Auth；当前架构只用应用网页登录 |
| 新连接保存成功但执行失败 | 预检不是连通性验证；核对兼容协议、根地址、鉴权、模型和目的地址限制 |
| 修改连接后旧会话不能发送 | 会话绑定修订；新建会话使用新连接，历史保留 |
| 达到金额上限 | 检查实际额度快照；原 Skill 仍可有金额守卫，可显式选择标准/自定义额度后手动重试 |
| 关闭金额限制后仍超时/触限 | 时长、轮次、输出和工具限制分别生效，不会一并关闭 |
| 导读没有高亮 | 引文未唯一匹配或证据为整块说明，查看页级解释 |
| 新 PDF 中没有旧批注 | 版本隔离是预期行为，需查看对应旧文件版本 |
| Skill 安装了但不能用于导读 | 检查启用状态、固定版本、所需工具和输出条件 |
| 重启后任务失败 | 中断不自动付费重跑，检查结果与部分输出后再决定 |
| Zotero 出现历史疑似重复 | 先核对来源标识、有效条目和 PDF 哈希；不自动合并或删除研究记录 |
