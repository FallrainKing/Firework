## 文档维护规则

本目录只保留现行指南、架构、接口、状态与后续计划。过期设计、阶段计划和重复验收记录已移除；需要追溯时使用 Git 历史，不在当前目录继续维护副本。

- 当前能力以 [项目状态](STATUS.md) 和对应代码为准；未来能力集中在 [后续计划](ROADMAP.md)。
- 文档不得保存密码、令牌、私钥或研究资料。
- 导读输出以 `app/reader/guides/schemas.py` 为权威，接口清单与应用 OpenAPI 同步。
- Skill 运行资源及上游来源声明保留在 `skills/`，不属于已移除的历史方案。
- 功能变化同步更新对应指南；验证记录注明范围，未执行的测试和恢复演练不写为通过。
