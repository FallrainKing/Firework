# Firework 项目状态

更新：2026-11-20。业务迁移 0014、独立身份 schema 1、Runner 协议 5。远程默认分支为 `main`，文档只描述当前实现。

## 已实现

| 模块 | 当前能力 | 关键边界 |
| --- | --- | --- |
| 工作台 | 最近阅读、领域导航、模板、真实 PDF 入口 | 缺 PDF 提示补充全文 |
| 文件版本 | 正文与补充材料、不可变版本、默认切换、批注列表及原件/带批注 PDF/Markdown 下载 | 旧版独立预览，三栏智能阅读使用默认版本；跨版本批注迁移未实现 |
| 阅读 | 多论文标签、可调三栏、批注/高亮/翻译、位置/草稿恢复 | 文件换版隔离，扫描材料无自动 OCR |
| 讨论 | 原生会话延续、模板、图片、选区、Enter 发送、进度/取消 | 图片理解取决于模型，费用是 CLI 估算 |
| 论文库/导入 | 分类、卡片、元数据编辑、PDF/arXiv/DOI/URL | 公开来源不保证获取全文 |
| Skills | ZIP 预检/安装、分类、版本、启停、资源、审计与最小验证 | 不执行任意上传脚本；安装不等于效果通过 |
| 前沿追踪 | 多维主题、arXiv/Crossref/GitHub、去重、时间线报告、审批入库 | 新主题默认暂停，元数据不等于全文审查 |
| 调度 | 会话/追踪间隔运行，启停、状态与错误 | 非任意 Cron，多副本与全局预算未实现 |
| 导读批注 | 明确确认触发 Skill，结构化总结/重点/解释，核验后高亮 | 最多 6 页文字材料，未接入图像/代码 |
| 认证与用户 | 登录、退出、改密、管理员账号管理、独立研究空间 | 公开注册关闭，当前仅原管理员可登录；没有共享库或跨账号协作 |
| 运维 | Compose、用户 Runner、增量迁移、备份/恢复脚本、零模型冒烟 | 生产全量恢复演练尚未完成 |

## 发布与验证

- 已部署 Firework 阅读工作台、独立账号与应用网页登录；公网不再启用浏览器 Basic Auth 弹窗。
- 公开注册关闭；当前只有原管理员可登录，普通账号即使启用也受发布限制。
- 最近代码验证：前端 196 项测试和构建通过；后端文件版本、导出、认证、隔离、相关业务与 SQLite 备份恢复回归 209 项通过。该数字不表示每次文档修改都重跑全仓库测试。
- 发布零模型冒烟 5/5。公网管理员登录、Secure Cookie、PDF Range 读取、退出失效及匿名私有资源 401 已验证。
- 验证未开放普通账号或执行生产全量恢复。已登录账号管理页尚未完成浏览器人工逐项验收。

## 未完成与限制

统一知识条目、显式长期记忆审核/召回、OCR/图像导读、完整 kelip/Nature 材料链、导读历史版本选择、全局费用账本、固定时刻日报/周报、站外推送、共享协作角色与多 Web 副本均未完成。详细优先级与验收见 [后续计划](ROADMAP.md)。

论文库、会话持久化及向量检索不能直接等同于统一知识管理与长期记忆。精读能力以实际读取材料、证据和已适配工具为准。

## 文件管理首批交付

已实现文件与批注统一入口、版本上传和去重、默认切换与索引补偿、旧材料会话保护及带批注 PDF 下载。兼容迁移以真实文件哈希关联旧批注；资料缺失时明确保留未解析记录。验证情况见 [变更记录](CHANGELOG.md)。本批未完成分类树、跨版本智能批注迁移、扁平化导出和完整会话材料版本界面。
