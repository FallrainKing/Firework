# Firework 视觉设计方向候选

调研：2026-11-21。本文件为选择建议，尚未更换当前产品主题；适配判断与示例配色为 Firework 的设计建议，不是来源项目的官方规格。

## 建议的三种完整风格

### A. 安静的研究工作台（首选）

以 Linear 的视觉克制为主，结合 Spectrum 的工具面板组织。浅色以中性灰和白色分层，深色以石墨灰分层；保留 Firework 的墨绿色强调色。论文和回答占据视觉中心，侧栏降低对比度；小圆角、轻边框，阴影用于菜单和弹窗。适合现在持续扩展的论文、Agent 和资料管理功能，改造成本较低。

### B. 学术阅读室

工具部分沿用 Spectrum/Apple 的清晰层级，报告内容使用更有编辑感的排版。工具背景接近中性暖白，PDF 保留原始白色；墨绿或靛蓝作交互强调，琥珀色仅作重点标记。适合强调精读、笔记、长期积累；需要单独检查暖色底与图表、彩色高亮的冲突。

### C. 科研控制台

采用 Carbon 的高效信息组织：规整网格、紧凑列表、明确状态列和参数分组。主色可用冷灰配蓝色。适合多任务运行、前沿监控和调试；阅读页仍应降低密度，避免整站成为控制面板。

## 首选方案的落地基线（待选定）

- 界面正文以 14px 为起点，辅助信息 12–13px，阅读结果 15–16px，行高约 1.7；中文随系统字体，不能靠大量 10px 小字挤空间。
- 以 4px 为间距单位，常用 8/12/16/24px；输入和按钮统一尺寸，桌面控件约 32–36px，高频触控区单独扩大。
- 示例色：工作区 `#F7F8FA`、内容 `#FFFFFF`、正文 `#20252B`、辅助文字 `#626B75`、强调色 `#237565`。这是候选色，实施时检查各状态的文字与背景对比度。
- 品牌色用于主要操作、选中和焦点；成功、警告、失败分别保留语义，不能仅用颜色表达状态。
- 图标统一线宽和尺寸。菜单浮层、弹窗、提示、拖拽和焦点统一规范，避免各页面自行加大 z-index。
- 论文库同时提供卡片与紧凑列表；阅读区保持三栏与独立滚动；会话页面突出问答与真实运行状态。
- 用设计变量逐步替换现有样式，先组件，再页面；保留 Vue、Hash 路由和现有业务接口。

## 实施与验收顺序

先用首页、论文库、三栏阅读各一张同数据原型比较方向，选定后统一色彩/排版/密度/层级变量，再改按钮、菜单、标签、输入框和对话框，最后覆盖配置与管理页。检查长标题、长 Markdown、错误、空状态、窗口缩小、键盘操作和深浅主题；不能只验收一张静态首页。
