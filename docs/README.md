## 维护规则

- `usage.md` 是唯一主使用指南，`架构.md` 是当前架构入口；按领域保留专题参考，避免并排维护重复版本。
- 未来能力只放后续计划，不列入现行路由或功能表。源码和 OpenAPI 是接口事实依据。
- 已完成的 Hash 改造计划合并到架构；旧 USER-GUIDE 合并到 usage；重复的阶段 CHANGELOG 已移除，历史通过 Git 查询。
- Runner 旧目标方案整理为当前参考，尚未实施的目标保留在后续计划；技能来源说明和项目内 NOTICE 不删除。
- 不提交凭据、研究数据、维护会话或备份；记录测试必须说明范围，不把模拟验证称为真实模型验证。
