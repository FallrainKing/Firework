# Firework

**通过现有智能体与 Skills 发现、阅读和管理研究资料的工作台。**

[English](README.md) · [使用指南](docs/usage.md) · [系统架构](docs/架构.md) · [文档目录](docs/README.md) · [后续计划](docs/ROADMAP.md)

Firework 将论文库、PDF 原文、批注与研究会话放在同一工作区。平台负责资料与任务管理，Claude Code 通过固定版本的 Skill 执行阅读、比较、导读和前沿发现。既可在服务器执行兼容 Skill，也可在本机用自己的智能体处理，经 MCP 回传成果，无需服务器重复推理。

当前功能基线：业务迁移 **0026**、身份 schema **3**、Runner 协议 **12**、Zotero 插件 **0.1.4**。已实现范围与验证边界见 [当前状态](docs/STATUS.md)。

完整的文档地图、历史需求完成度和待补框架见 [项目总览与需求核对](docs/PROJECT-AUDIT.md)（2026-11-22 核对）。

## 主要功能

- 阅读起始工作台，提供最近论文、领域分类和任务模板。
- 多论文标签、可调整三栏：辅助阅读、PDF 原文、关联智能体会话；恢复页码、缩放、布局和草稿。
- PDF/arXiv/DOI/公开链接导入、研究检索、个人分类树重命名/移动/回收站恢复；卡片显示图片、题名、作者/单位及摘要。
- 正文和补充材料的不可变版本，默认版本选择，以及原件、带批注 PDF、批注 Markdown 下载。
- 持久会话、流式正文、选区/模板/图片、Enter 发送、进度与取消；Run 事件、材料检查、脱敏调试包和分支预览。
- 明确触发的结构化导读与批注；统一高亮和备注，AI 批注可采纳为个人副本，翻译可定位原文；打开论文不会自动生成。
- 前沿主题、多来源发现、去重、堆叠时间线报告与审批入库；间隔任务默认先暂停。
- Skills ZIP 预检、分类、显示名、版本、启停与功能可见性；Web 编写指令和发布修订，安装不执行任意脚本。
- 账号独立的模型连接、供应商预设、加密 Key、网络/最小模型测试、能力声明与额度；输入区底部查看连接并预览切换分支。
- 版本化研究产物、附件与 PDF 证据；知识候选审核、发布、撤销和文本召回。
- 本机 stdio MCP：授权页面上下文读取，论文材料获取，本机导读/批注/翻译/前沿报告回传及幂等回执。
- 可选的隔离 Claude 原生终端、文件下载和成果收录；终端不自动挂载技能库或第三方 MCP。
- Zotero 10.0.6–10.x 插件手动双向书目、分类、标签和 PDF 交换，不调用研究模型。
- 独立账号研究数据库、文件、向量集合和运行空间；当前公开注册关闭，默认仅原管理员登录。

执行方案、研究产物与知识审核已实现。尚未完成的主要能力包括：任意第三方 MCP 管理、本机进程 Bridge、多智能体运行时、语义长期记忆、Zotero 成果与批注回流、完整 Runner 容器化及恢复演练。视觉与1M仍需实际验证；最小文本测试不证明这些能力。历史 PDF 可用独立链接阅读，但同一论文多版本的内部并列标签尚未提供。

## 使用顺序

1. 登录后，在用户菜单 → **模型连接** 配置 Anthropic Messages 兼容 API；原管理员也可保留已有连接。
2. 在 **任务额度** 选择默认预设。新预设可关闭 CLI 金额守卫，但仍保留轮次、输出、工具和时长限制。
3. 导入一篇 PDF，从左侧论文进入阅读，先发送一个小问题，再按需启用导读、比较或追踪。
4. 已有会话保持连接绑定；需要切换时，在底部连接条预览并确认新分支，历史记录保留。
5. 本机研究通过外部接入页下载 MCP/Skill 包，配置自己的智能体后回传结果；页面共享默认关闭。

保存配置、查看论文和下载既有批注不调用研究模型；普通导入、发送任务、确认导读和启用调度可以产生模型用量。完整操作见 [usage.md](docs/usage.md)。

## 架构与安装

```text
浏览器工作台 → FastAPI / 认证与账号工作区
                   ├─ SQLite / PDF / 附件 / Skills
                   ├─ bge-m3 / Qdrant
                   └─ 私有 Socket → 宿主 Runner → Claude Code / 模型 API
                                                   └─ 受限 research MCP 工具
```

前端为 Vue 3/TypeScript，后端为 FastAPI/Python。Compose 提供 app、qdrant、backup，Runner 是单独的宿主用户服务；只启动容器不能运行智能体。当前为单 Web worker，尚非多副本架构。可选原生终端按会话进入隔离容器，Runner 编排仍运行在宿主。

```sh
git clone https://github.com/FallrainKing/Firework.git
cd Firework
cp .env.example .env
```

启动前需准备 Python 3.12+、Docker/Compose、Claude Code CLI、模型缓存及实际 HTTPS Origin；调整仓库中的固定端口/网卡、路径和服务模板，再交互初始化管理员。生产保留 Secure Cookie，Key 不放普通 `.env`。完整步骤见 [环境与部署](docs/enviroment.md) 和 [开发指南](docs/DEVELOPMENT.md)。

## 外部智能体与执行方案

设置中可管理执行方案、模型目录及内置 MCP 权限，并签发外部智能体专用授权。下载通用论文操作 Skill 包，按 [MCP 配置说明](plugins/agent-skill/firework-paper-ops/references/mcp.md) 注册本机 stdio 服务，令牌存入私有文件。其他兼容智能体可查询/修改书目、读取 PDF、提交导读、批注、翻译和前沿报告；不调用服务器模型。

用户菜单可显式共享当前页面；本机按窗口 ID 和修订读取，过期或切页后重新确认。成果写入另需相应权限，候选论文和知识仍经过审批。见 [完整接入说明](docs/EXTERNAL-AGENT-API.md) 和 [本轮交付及边界](docs/READING-CONTEXT-DELIVERY.md)。

最新联合验证：后端363通过、5跳过，前端269通过及生产构建通过。本机stdio到HTTP的回传链路已在隔离环境验收；未执行生产付费模型、视觉或长上下文测试。
