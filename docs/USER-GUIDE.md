# 使用指南

适用：2026-11-19 阅读工作台版本。页面操作负责管理；研究内容通过现有智能体与所选 Skill 处理。

## 1. 首页与添加论文

顶部入口依次为读论文、前沿追踪、论文比较、定时任务、论文库管理。左侧提供新建阅读、最近论文和领域分类；中央提供研究输入和常用任务模板。

从“搜索 / 导入论文”添加材料：

| 渠道 | 适用输入 | 结果 |
| --- | --- | --- |
| PDF 上传 | 本地 PDF | 导入、解析、向量化后进入论文库 |
| arXiv | arXiv 标识或链接 | 按来源获取论文及可用全文 |
| DOI | DOI 标识或链接 | 获取书目信息与可获得的公开全文 |
| 公开 URL | 公开论文页面或 PDF 链接 | 按实际可用资源处理，失败保留原因 |
| 发现结果批准 | 前沿追踪中的候选论文/项目 | 去重后加入对应资料库 |

导入由现有任务链执行，可能调用智能体。跟踪导入状态，失败后先看原因再重试。DOI 或网页条目不保证有可下载全文；缺少 PDF 时补充全文即可，不能以书目信息充当阅读全文。

在论文库中按分类、阅读状态和关键词筛选；论文卡片展示预览图、题目、作者/单位及摘要，缺失元数据可编辑。项目有独立入口，不伪装为论文 PDF。

## 2. 阅读工作区

点击左侧论文直接进入原文，恢复已有会话和阅读位置。标签栏位于三栏上方，＋可选已有论文或导入；已打开论文切换到原标签。关闭标签仅关闭工作区，不删除论文、批注或阅读记录。

- 左侧：导读、目录、批注、高亮、译文、信息。
- 中间：PDF，工具栏位于 PDF 栏顶部；支持页码、缩放、选择及笔迹。
- 右侧：当前关联论文的智能体会话、模板、图片和输入框。

拖动分隔线调整宽度，左右栏可收起。每篇论文保存页码、缩放、辅助页状态、会话与草稿；布局随工作区保存。扫描 PDF 无文字时，当前文本导读不会自动进行 OCR。

## 3. 导读与智能批注

打开新论文只显示输入框建议：**试试：自动批注 / 阅读论文**。

1. 选择“自动批注”，展开配置。
2. 选择可用技能、修改阅读目标，设置材料页数和重点数量。
3. 点击“确认生成批注”，才开始执行 Skill。
4. 完成后左侧展示总结、路线、重点、重要性理由和解释；原文显示经过核验的高亮及页边标记。

当前内置技能默认最多 6 页、6 个重点，可选 1–6 页、1–10 个重点。读过的页、材料缺口和费用估算会显示；部分材料不会被宣称为全文精读。不具备图像、OCR 和代码分析能力。

点击原文页边标记展开对应解释；已生成解释、切页、隐藏图层均不调用模型。无法唯一定位的内容只显示页级笔记；混合证据会标明部分引文高亮、另有页级证据。

AI 层可隐藏；标记可移除和恢复；“采纳为我的批注”创建可编辑个人副本，后续生成不会覆盖。任务失败可移除记录，再明确确认重试。相同版本、技能及配置优先复用，刷新不会重复生成。

选择“阅读论文”并确认则创建阅读会话，调用现有阅读 Skill；它与结构化导读生成是两个入口。

## 4. 讨论、模板与图片

输入文字后 Enter 发送、Shift+Enter 换行；中文输入法候选确认不会误发送。模板将要求填入输入框，可修改后提交。支持图片上传、粘贴或拖入，发送前可预览、移除；可与选中原文一起发送。

普通讨论支持最多 3 处原文上下文和 3 张附件；图片支持 PNG/JPEG、单张最多 5 MiB，并有尺寸限制。图片理解还取决于当前模型真实视觉能力；能上传不等于模型已经看懂。结构化导读暂不使用图片附件。

会话按任务保留，可继续上次原生会话。运行详情显示工具、状态和用量，执行中可取消。CLI 费用为估算，未知显示未提供。导出 Markdown 是快照，不会自动写入长期记忆。

## 5. 前沿追踪

新建主题，可填研究目标、领域、关键词、作者、团队与排除项，选择 arXiv/Crossref/GitHub 和分类。主题默认暂停；可以先执行一轮小范围验证，再按需启用间隔调度。

报告按日期堆叠，最新在上，可展开历史、标记已读并导出。平台将发现与已有资料去重，区分新增、更新和已知未变化。来源失败、截断和覆盖不足会显示。

候选论文或项目先待批准，可批准、忽略或恢复；批准时选分类。论文和项目分开保存，已有资料不会因重复批准多次入库。不要把元数据级发现当作全文审查。持续启用会产生后续模型任务，需结合单轮额度与每日次数管理。

## 6. 技能与用户设置

右上角用户入口提供本地用户资料、偏好及技能管理相关入口。当前是本地单用户标识，不是多用户账号与权限系统。

技能 ZIP 先预检，再配置名称、分类、标签和预算档位并安装；可查看版本、资源和审计、启用/停用、执行最小验证。安装包不会自动运行其中脚本；只有已登记工具和资源可供执行。技能安装与真实效果验证不同，导读技能还需满足专门的工具与输出条件。

## 7. 常见问题

| 现象 | 处理 |
| --- | --- |
| 论文打开后提示没有全文 | 从补充全文入口上传或导入 PDF |
| 自动批注按钮没有立即生成 | 先检查配置，再点击确认；这是预期行为 |
| 只有页级标记，没有高亮 | 原文未唯一匹配或使用整块证据，保留页级定位以避免误标 |
| 智能体离线或协议不匹配 | 由维护者检查宿主 Runner 与应用版本 |
| 翻译或导读失败 | 查看原因，可移除失败记录后明确重试；不需要删除论文 |
| 更新 PDF 后旧批注未出现 | 旧产物按文件版本隔离，不能直接贴到新原文 |
| 新上传 Skill 不在导读选择器 | 工具、状态、版本或输出额度尚不兼容 |
